# Simple .NET System (sistema .NET simples)

Sistema simples desenvolvido em **C# com .NET WinForms**, utilizando o **VS Code** como ambiente de desenvolvimento.

O objetivo deste projeto é ensinar fundamentos de programação através da implementação de várias aplicações comuns do dia a dia, mantendo o código **simples e acessível para iniciantes**.

> Este projeto é didático. A ideia não é ter a melhor arquitetura possível, mas sim permitir que qualquer pessoa consiga entender, replicar e evoluir o código. Dito isto, apesar de ser um projeto para iniciantes, é recomendado que se tenha conhecimento básico de WinForms, C# e banco de dados, já que são tecnologias cruciais neste projeto.

---

## Objetivos

- Demonstrar conceitos básicos de programação dentro do ecosistema .NET
- Trabalhar com diferentes tipos de aplicações em um único projeto
- Incentivar a prática e evolução do código
- Servir como base para iniciantes explorarem, testarem e melhorarem o projeto

---

## Módulos do sistema:

O sistema é composto por vários módulos:

### CRUD com To Do List

- Adicionar, editar e remover tarefas
- Marcar tarefas como concluídas

### Visualizador de Arquivos de Mídia

- Abrir e visualizar arquivos de mídia locais

### Tabela de Operações Matemáticas

- Clássica tabela das principais operações aritiméticas da matemática

### Calculadora Completa

- Operações básicas e intermediárias

### Conversor de Unidades

- Conversor de vários tipos de umedidas para outros. Binário pra decimal, decimal pra hexadecimal, etc

### CRUD com Banco de Dados

- Persistência de dados
- Operações de criação, leitura, atualização e exclusão

### Jogo da Velha

- Jogo local simples para dois jogadores

### Sistema de Login Simples

- Cadastro e autenticação básica de usuários
- Senhas hash
- Token JWT

### Consumidor de API Pública

- Requisições HTTP
- Consumo e exibição de dados externos

### Agenda de Contatos

- Cadastro e gerenciamento de contatos em BD

### Gerador de Senhas

- Criação de senhas aleatórias com diferentes critérios

### Sistema de Pizzaria

- Simulação de pedidos
- Cálculo de valores
- Cadastro de clientes em BD

## Como Executar o Projeto

1. Clone o repositório, usando Git Bash ou o terminal do sistema operacional:

```bash
git clone https://github.com/1Lino/Simple-.NET-System.git
```

2. Acesse a pasta do projeto:

```bash
cd Simple-.NET-System
```

3. Execute:

```bash
dotnet run
```
